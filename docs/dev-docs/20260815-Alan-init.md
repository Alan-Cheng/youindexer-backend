# 專案初始化紀錄

- 日期：2026-08-15
- 建立者：Alan
- 專案：YouIndexer Backend

## 初始化目的

建立 YouIndexer 後端的基礎開發環境，提供 HTTP API、資料驗證、PostgreSQL、Redis、背景任務與資料庫 migration 所需工具，並以 uv 統一管理 Python 虛擬環境、依賴與 lockfile。

## Python 與依賴管理

專案設定於 `pyproject.toml`，目前要求 Python `>=3.14`，套件版本解析結果鎖定於 `uv.lock`。

| 套件 | 用途 |
| --- | --- |
| `fastapi` | 建立 REST API，並自動產生 OpenAPI、Swagger UI 與 ReDoc 文件。 |
| `uvicorn[standard]` | 執行 FastAPI 的 ASGI server；standard extras 包含開發時常用的效能與 reload 相關套件。 |
| `pydantic` | 定義、驗證及序列化 API request、response 與應用程式設定資料。 |
| `psycopg[binary]` | PostgreSQL driver，負責 Python 與 PostgreSQL 之間的連線與 SQL 執行。binary extra 讓本地環境不需自行編譯 driver。 |
| `sqlalchemy` | Python ORM 與 SQL toolkit，用於定義資料模型、建立查詢及管理資料庫 session。PostgreSQL 連線沿用 `psycopg` driver。 |
| `redis` | Redis Python client；可用於快取、狀態儲存，以及 Celery broker/backend 連線。 |
| `celery` | 執行非同步背景任務與排程工作的 task queue。此階段僅安裝套件，尚未建立 Celery app 或 worker 設定。 |
| `alembic` | 管理資料庫 schema migration。此階段僅安裝套件，尚未執行 `alembic init` 或建立 migration。 |

## 基礎服務

`docker-compose.yml` 定義以下本地服務：

| 服務 | Image | 預設連接埠 | 用途 |
| --- | --- | --- | --- |
| PostgreSQL | `postgres:17-alpine` | `5432` | 主要關聯式資料庫。 |
| Redis | `redis:7-alpine` | `6379` | 快取及後續 Celery broker/backend。 |

兩個服務都設定 healthcheck、named volume 與 `unless-stopped` restart policy：

- `postgres_data` 保存 PostgreSQL 資料。
- `redis_data` 保存 Redis 資料。
- PostgreSQL 使用 `pg_isready` 檢查服務狀態。
- Redis 使用 `redis-cli ping` 檢查服務狀態。

本地環境參數範例放在 `.env.example`，實際 `.env` 已加入 `.gitignore`，避免密碼或個人設定被提交。

## 目前應用程式結構

```text
app/
├── main.py              # FastAPI app 與 router 註冊
├── config.py            # DATABASE_URL、REDIS_URL 設定
└── api/
    └── v1/
        └── health.py    # PostgreSQL 與 Redis health check
```

目前提供 `GET /api/v1/health`：

- 對 PostgreSQL 執行 `SELECT 1`。
- 對 Redis 執行 `PING`。
- 兩者同時正常時回傳 HTTP 200 與 `healthy`。
- 任一服務無法連線時回傳 HTTP 503 與 `unhealthy`。

FastAPI 文件入口：

- Swagger UI：`/docs`
- ReDoc：`/redoc`
- OpenAPI schema：`/openapi.json`
